# /arena-brief

1. Read the challenge text and any files twice. Note the stack in one line if there is a repo.
2. Say the mode in one line: Persuade, Experience, Read or Operate (see the art-direction skill). Not a website? Switch to /arena-any.
3. Ask the human, in one message, with a default for each:
   - Material: what real things exist (photos, product, numbers, names, a place)?
   - Their own three ideas, rough is fine, and one opinion about how it should feel.
   - Three things it must not look or sound like.
   - The one action or feeling the audience should leave with.
   If they say "go", infer, state the inferences in three lines, and continue.
4. Write the inventory: 8 to 12 facts that belong only to this brief (name and its meaning, place, numbers given, the constraint it lives with, materials, rituals, printed things of its world, audience moment). Mark assumptions "(assumed)".
5. Write the argument: the page as claims with proof, one line per section.
6. Stop. Do not propose ideas, layouts or code yet.
